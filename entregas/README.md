# Entregas

Cada estudiante (o grupo) crea una carpeta con su usuario de GitHub:

```
entregas/
└── usuario-github/
    ├── ej01.md          Análisis basado en docs/plantilla-analisis.md
    ├── ej01/            (opcional) Código del rediseño
    ├── ej02.md
    └── ...
```

No modifique archivos fuera de su carpeta.
